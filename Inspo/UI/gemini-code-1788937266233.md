# Editorial Reader UI: Design Intent & System Specifications

## 1. Editorial Design Philosophy
The primary intent of this reader interface is to project institutional credibility, intellectual weight, and timeless clarity inspired by traditional Swiss broadsheets.
* **Radical Minimalism:** Decorative digital artifacts such as drop shadows, saturated backgrounds, and rounded corners (`border-radius: 0px`) are entirely avoided.
* **Content Hierarchy:** High visual contrast and disciplined negative space direct the reader's attention to news substance rather than interface chrome.

## 2. Color Palette & Semantic Tokens
The palette enforces strict contrast ratios, favoring a clean monochrome base with selective editorial accents. To ensure local rendering processes remain efficient, modern CSS relies heavily on native variables mapped to semantic tokens.
* **Canvas Background (`--bg-primary: #FFFFFF`):** Uncoated pure white creates a stark, authentic newsprint feel that optimizes long-form reading comfort.
* **Ink Black (`--text-main: #111111`) & Muted Charcoal (`--text-muted: #555555`):** Deep ink ensures high-contrast readability for primary copy, while charcoal softens secondary excerpts and bylines.
* **Editorial Dividers (`--border-light: #E5E5E5`) & Signal Red (`--accent-red: #D80000`):** Subtle hairline borders isolate layout compartments. Signal red is reserved strictly for live markers and category tags, never as a background.

## 3. Typographic Architecture
The system establishes authority through a stark contrast between classic editorial serifs and functional sans-serifs, mapping perfectly to a traditional Swiss broadsheet. For reference, Neue Zürcher Zeitung utilizes custom typefaces like NZZ Serif (based on Pensum Pro) and NZZ Sans (based on GT America) alongside fonts like Damien Text and Beausite across its digital ecosystem. Use the following open-source equivalents or commercial licenses if available:

* **Headline Serif (`Playfair Display` or `Pensum Pro` / `Damien Text`):** Weight 700, leading `1.1em`, tracking `-1px`. Used strictly for article titles and major structural headers.
* **Editorial Body (`Lora` or `Merriweather`):** Weight 400, leading `1.6em`. Optimized for extended, fatigue-free reading sessions without compromising visual rhythm.
* **System Sans-Serif (`Inter` or `GT America` / `Beausite`):** Weight 500 or 600, uppercase, expanded tracking (`+0.5px` to `+1px`). Used exclusively for timestamps, bylines, category tags, and navigation.
* **Vertical Alignment:** Text elements maintain strict typographic baseline alignment across column breaks to reflect physical typesetting traditions.

## 4. Component Structures & DOM
Avoid nested wrapper `div`s to keep the DOM tree shallow and performant.
* **Navigation:** Sticky top-bar featuring a centered, scaled serif logo. Utilize flexbox for horizontal category links.
* **Layout Grid:** CSS Grid defining a maximum `1200px` container, splitting into a 70% primary story column (hero article) and a 30% right-hand chronological news rail.
* **Article Cards:** Zero border-radius (`0px`), zero box-shadows. Delineate sections using only `1px solid` bottom borders (`var(--border-light)`).

## 5. Responsive Behavior & Accessibility
Ensure the interface adapts fluidly across viewports without relying on heavy JavaScript listeners.
* **Breakpoints:** Collapse the 2-column grid into a single-column linear feed at `max-width: 900px`.
* **Contrast Ratios:** The white-and-ink-black palette guarantees WCAG AAA compliance for readability.
* **Extended Displays:** The `1200px` max-width container keeps line lengths readable even when previewing the UI on ultrawide or extended external monitors.
