# NZZ Instagram Carousel Design System: Automated Pipeline Blueprint

## 1. Core Specifications & Canvas Logic
* **Canvas Dimensions:** `1080px` (Width) x `1350px` (Height) — 4:5 Vertical / Portrait orientation.
* **Resolution:** 72 DPI (Standard Web), export as high-quality PNG or JPG (85%+ quality).
* **Carousel Length:** Strictly 7 slides per post.

### Safe Zones & Margins
Instagram native UI (profile name, pagination dots, like/comment buttons) overlays the image. The coding agent must respect these boundaries:
* **Global Padding:** `80px` margin on the left and right edges.
* **Top Safe Zone:** Keep critical text `150px` away from the top edge.
* **Bottom Safe Zone:** Keep critical text and logos `250px` away from the bottom edge.
* **Content Box:** All primary text and UI elements must render within the central `920px` by `950px` container.

---

## 2. Typographic Hierarchy (NZZ Identity)
NZZ’s visual authority stems from a strict pairing of traditional serif typography for impact and modern sans-serif for data and clarity. 

### A. Primary Typeface: Serif (Headlines & Pull Quotes)
* **Font Family:** *GT Sectra*, *Pensum Display*, or *Damien Text*. (Google Fonts fallback: *Playfair Display* or *Lora*).
* **Headline (Slide 1):** 
    * Size: `96px` – `112px`
    * Weight: Bold (`700`)
    * Line Height: `1.1em` (Tight)
    * Letter Spacing: `-1px`
* **Pull Quotes (Slides 2-6):**
    * Size: `72px` – `84px`
    * Weight: Medium (`500`) or Italic
    * Line Height: `1.2em`
    * Letter Spacing: `0px`

### B. Secondary Typeface: Sans-Serif (Body, Badges, & UI)
* **Font Family:** *GT America* or *Beausite*. (Google Fonts fallback: *Inter*, *Helvetica Neue*, or *Arial*).
* **Body Text (Slides 2-6):**
    * Size: `40px` – `48px`
    * Weight: Regular (`400`)
    * Line Height: `1.5em` (Optimized for mobile readability)
* **Category Badges (e.g., "DATENANALYSE", "GEOPOLITICS"):**
    * Size: `28px`
    * Weight: Bold (`700`)
    * Text Transform: UPPERCASE
    * Letter Spacing: `+3px`
* **Pagination & Small UI (e.g., "2/7"):**
    * Size: `24px`
    * Weight: Medium (`500`)

---

## 3. Color Palette & Theming Constraints
Avoid saturated or neon colors. The palette must remain editorial, muted, and high-contrast.

* **NZZ Core Black:** `#111111` (Default for text on light backgrounds).
* **NZZ Core White:** `#FFFFFF` (Default for text on dark backgrounds; also used for minimal slide backgrounds).
* **NZZ Accent Red:** `#D80000` (Use strictly for small UI indicators, lines, or specific logo treatments—never as a background color).
* **Muted Editorial Backgrounds:**
    * **Soft Grey:** `#F4F4F6` (Standard background for body text/context slides).
    * **Muted Sand:** `#E3C068` (Reserved for Data, Finance, or Analysis slides).
    * **Soft Lavender:** `#E1DCE6` (Reserved for Opinion, Arts, or Culture pieces).

---

## 4. Slide-by-Slide Structural Blueprints

### Slide 1: The Hook (Attention/Headline)
* **Layout Rule:** Full-bleed background image with a vertical gradient overlay to ensure text legibility.
* **Gradient Spec:** `#000000` at `0%` (Bottom) transitioning to `#000000` at `0%` opacity (Top), starting at the `40%` vertical mark.
* **Component Placement:**
    * NZZ Logo: Top-Left (Inside safe zone: X: `80`, Y: `150`). Color: `#FFFFFF`. Width: `120px`.
    * Category Badge: Bottom-Left (Above Headline). Color: `#E3C068` or `#FFFFFF`.
    * Headline: Bottom-Left (Below Badge, adhering to bottom safe zone). Max characters: ~60. Color: `#FFFFFF`.

### Slides 2–6: The Context (Story & Data)
The coding agent should cycle between these layouts to prevent visual fatigue:
* **Layout A (Text Heavy):** Solid color background (`#F4F4F6`). Headline/Subhead top-aligned; Body text center-aligned. Logo omitted.
* **Layout B (Image + Card):** Full-bleed image. A solid `#FFFFFF` box (Opacity: `95%`) overlaid in the center or bottom half containing the Body text.
* **Layout C (Pull Quote):** Solid background (`#E1DCE6`). Large Serif quote centered on the canvas. Add a `-` and the speaker's name in Sans-Serif below.
* **Pagination Rule:** Render text (e.g., `2/7`) at Bottom-Right (X: `1000`, Y: `1250`). Color: `#888888`.

### Slide 7: The CTA (Conversion)
* **Layout Rule:** Minimalist. Solid Background (`#111111` or `#FFFFFF`).
* **Component Placement:**
    * Large NZZ Logo: Center aligned (Y: `400`). Width: `300px`.
    * Serif Header: Center aligned (Y: `600`). Text: "Understand the world." (or similar).
    * Sans-Serif CTA Box: Center aligned (Y: `800`). A stroked box (Border: `2px solid`) containing text like "Read on NZZ.ch".

## 5. AI Image Generation & Compositing Rules
* **Prompt Engineering Prefix:** For all image generation API calls, prepend: *"Editorial photography, documentary style, realistic, dramatic natural lighting, high contrast, photojournalism, minimalist composition, 4:5 aspect ratio."*
* **Image Sizing:** The agent must crop or resize generated images to exactly `1080x1350px` using a center-crop method before applying text or gradients.
* **Contrast Checks:** If placing dark text on an image, the agent must apply a white overlay (Opacity `70%`). If placing light text, apply a black overlay (Opacity `70%`) or the specified Slide 1 gradient.
